Memory 系统：记忆是 Agent 的灵魂

OpenClaw 深度解析系列 · Day 5

没有记忆的 AI 就是金鱼。OpenClaw 的 Memory 系统分两层：短期日志+长期记忆，每周整理提炼精华。

双层架构

每日日志（memory/YYYY-MM-DD.md）：会话结束后写，记录当天发生的事、发现的重要信息、用户交代的待办。

长期记忆（MEMORY.md）：每周（通过 heartbeat）从日志提炼精华，更新进去，删除过时信息。模拟人类的"事后复盘"。

MEMORY.md 写法

## 关于 Sam
- Telegram，中文为主，喜欢简洁
## 重要项目
- Quantrade 量化交易，初始 10000 USDT
- learn2pro 博客，Hexo + gh-pages
## 重要教训
- HDD NTFS 只读，需重新挂载
## 待办
- [ ] 接入邮件 Skills

关键原则

精炼：只留真正重要的决策、偏好、教训。不要流水账，越大越慢越失效。

明天聊 Skills——给 AI 装上工具，让它真正能"做事"。
