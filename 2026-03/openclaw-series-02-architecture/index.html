OpenClaw 核心架构：四大支柱

OpenClaw 深度解析系列 · Day 2

理解 OpenClaw 的核心是理解它的四大支柱：Workspace、Memory、Skills、Channel。

整体架构

类比公司：Workspace = 办公室；Memory = 档案室；Skills = 员工技能库；Channel = 前台。Claw Core 就是 CEO，调度四个部门协同工作。

Workspace：AI 的工作目录

设计原则：所有 AI 需要知道的东西都在文件里。不依赖数据库，纯文件系统。

Memory：认知连续性

两层：每日日志（memory/YYYY-MM-DD.md）+ 长期记忆（MEMORY.md）。灵感来自人类的日记+年度总结。

Skills：能力模块化

核心是写一个 SKILL.md 定义工具，不需要写代码。内置 Skills 包括 weather、discord、coding-agent、clawhub。

Channel：多渠道接入

一个 AI，多个平台在线。用户不需要知道消息来自哪里，AI 也不需要关心。
