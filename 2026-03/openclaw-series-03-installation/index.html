安装与配置：从零跑起来

OpenClaw 深度解析系列 · Day 3

从零把 OpenClaw 跑起来，整个过程大约 10 分钟。

安装

npm install -g openclaw
openclaw init
openclaw gateway start

配置

model: minimax-portal/MiniMax-M2.5
skills:
  enabled: [coding-agent, clawhub, find-skills]
channel:
  telegram:
    enabled: true
    bot_token: "YOUR_BOT_TOKEN"

配置 Telegram

找 BotFather，发 /newbot，拿到 token 填进配置，然后 openclaw gateway restart。

验证

openclaw chat "你好"

或直接给 Telegram Bot 发消息测试。

踩坑

问题方案
端口占用换端口或 kill 进程
Bot 不响应检查 token，设 webhook
权限报错确保 ~/.openclaw 权限正确
