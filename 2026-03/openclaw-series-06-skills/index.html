Skills 生态：能力模块即插即用

OpenClaw 深度解析系列 · Day 6

Skills 是 OpenClaw 的插件系统。不需要写代码，配一下就能给 AI 装上新能力。

什么是 Skill

核心是 SKILL.md，用 Markdown 定义工具的用途和参数。AI 读完就知道怎么用。

内置 Skills

Skill功能
weather查天气预报
discordDiscord 运营
coding-agentClaude Code 子任务
clawhub社区 Skills 管理

ClawHub 生态

clawhub search "email"
clawhub install email-skill

自定义 Skill

写一个 SKILL.md，放到 skills/ 目录即可。不需要写代码。
